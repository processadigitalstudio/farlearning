# Unit 2: Accidents — Interactive English II

Clase interactiva para la Unidad 2 del curso Interactive English II (Tweetalig / English Discoveries).

## Contenido

- **Vocabulary** — 32 palabras en 3 grupos con traducción y ejemplos
- **Warnings** — Frases de advertencia, frases para ignorarlas, letreros escritos, situaciones interactivas
- **Grammar** — Past Perfect Simple y Progressive con tabla resumen
- **Quiz** — 10 preguntas con retroalimentación bilingüe
- **Role-play** — Diálogo modelo + ejercicio de completar + tarea oral

## Cómo usar

Abre `index.html` directamente en el navegador, o despliega en GitHub Pages / Netlify.

## Despliegue en GitHub Pages

1. Sube esta carpeta a un repositorio de GitHub
2. Ve a **Settings → Pages**
3. En **Source** selecciona `main` branch, carpeta `/ (root)`
4. Guarda — en unos minutos tendrás una URL pública
